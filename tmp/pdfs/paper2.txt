Abstract
Empowering large language models with long-term memory is crucial for building agents that adapt
to users’ evolving needs. Existing evaluations of this capability typically interleave preference-
related dialogues with irrelevant conversations, reducing the task to needle-in-a-haystack retrieval
while ignoring relationships between events driving user preference evolution. Such settings
overlook a fundamental characteristic of real-world personalization: preferences emerge gradually
and accumulate across interactions within noisy contexts. To bridge this gap, we introduce
PERMA, a benchmark designed to evaluate persona consistency over time beyond static preference
recall. Additionally, we incorporate(1) text variabilityand(2) linguistic alignmentto simulate
erratic user inputs and individual idiolects in real-world data. PERMA consists of temporally
ordered interaction events spanning multiple sessions and domains, with preference-related queries
inserted over time. We design both multiple-choice and interactive tasks to probe the model’s
understanding of persona along the interaction timeline. Experiments demonstrate that by linking
related interactions, advanced memory systems extract precise preferences and reduce token
consumption, outperforming traditional semantic retrieval of raw dialogues. Nevertheless, they
still struggle to maintain a coherent persona across temporal depth and cross-domain interference,
highlighting the need for more robust personalized memory management in agents.

1 Introduction
The rapid advancement of large language models (LLMs) [14, 36, 40] has catalyzed a shift from static knowledge
access paradigms to interactive agents capable of sustained engagement [78]. In this new paradigm, long-term
memory is no longer merely a tool for knowledge retrieval, but a prerequisite for maintaining coherent user
representations across interactions. A reliable memory-equipped agent not only stores past information, but
continuously constructs and updates a consistent persona state that reflects users’ constraints and behavioral
tendencies over time [18].

Despite these requirements, inherent limitations in context window size and token costs present significant
bottlenecks [45, 48, 71]. To mitigate these challenges, recent progress in retrieval-augmented generation
(RAG) [12, 28, 29, 70] has bolstered LLMs’ capacity to extract relevant factual knowledge [5, 27, 60, 79]. To
further refine retrieval quality, several approaches have introduced structured memory indices [59, 61, 62],
such as tree- [42, 44] and graph-based [6, 30, 53] representations. Complementing these retrieval techniques,
reinforcement learning (RL) has been incorporated to optimize memory utilization in long-context settings [33,
65, 68]. Beyond generic storage mechanisms, personalization-oriented agents leverage modular memory
architectures and context-aware memory structures. These agents emphasize capturing user profiles and
preferences to inform downstream conditioning for long-horizon planning and lightweight deployment [10, 25].
While these architectural innovations endow agents with the potential for long-range memory, the method for
quantifying their personalized performance within complex real-world scenarios remains an open challenge.
Along this line, empirical studies [19, 75] have underscored the inherent difficulties in verifying user-centric
personalization, a task typically benchmarked by preference recall fidelity and robustness to token-level noise
across extended interactions [32]. While current LLMs excel at factual retention [52], effective personalization
necessitates a paradigm shift [2]: treating user preferences not as static attributes, but as evolving behavioral
patterns that must be contextually inferred and extracted during ongoing task interactions [20, 64]. Thus,
the primary bottleneck is not simple memorization, but theinterpretation,integration, andretrieval
of preference signals that are often latent, incrementally expressed, or obscured by conversational noise.
Unfortunately, as illustrated in Figure 1 (a), existing evaluation frameworks remain insufficient for assessing
the longitudinal consistency of persona understanding, due to three limitations: (1)Preference-Centric
F raming: Existing protocols [75] construct the origins of preferences using static statements from a user
perspective, rather than capturing the adaptive nature of preferences through iterative feedback. Such a
formulation turns the conversation between user and assistant into a preference briefing, thereby overlooking
how preferences manifest through event-driven dialogues. Consequently, the resulting evaluation ignores the
interactive nuances of real-world deployment, failing to represent noise-rich scenarios such as ambiguous
requests [23]. (2)Static User Modeling: As preferences are predefined prior to dialogue, models are evaluated
based on isolated user preferences [11, 75], treating them as static snapshots and neglecting cross-session
dependencies that are essential for assessing agents’ ability to reason over continuous interactions. It remains
difficult to verify whether a model can achieve the cross-domain synthesis and retrieval required for complex
queries [19], often leading retrieval-based approaches to appear effective under recall-oriented settings while
their performance is overestimated [58]. (3)Outcome Assessment: Ideally, a memory-augmented agent
should progressively integrate interaction histories and user preferences to enhance the efficiency of subsequent
sessions, thereby reducing token overhead and minimizing the need for redundant repetitive user prompting.
Current evaluation paradigms primarily focus on the capabilities of standalone LLMs and assess performance
mainly based on the final LLM outputs, conflating memory retrieval with the generation process in memory
systems rather than evaluating them separately. As a result, the quality and efficiency of the underlying
memory systems, as well as memory utility in interactive scenarios, remain unexamined. These limitations
highlight the need for alignment between benchmark construction and real-world interaction scenarios.
To this end, we introducePERMA, a benchmark designed to evaluate the maintenance of persona states,
defined as a combination of dynamic user preferences and episodic memory. PERMA models personalization
as a temporally evolving state derived from interaction events, where each session addresses specific task
requirements within a targeted topic. Through this process, fine-grained preference details are not explicitly
given as standalone statements, but are inferred from how users articulate requests, provide feedback, and
refine constraints across turns. These extracted preference signals, together with interaction history, are
integrated into the evolving persona state, progressively enriching the user profile. As illustrated in Figure 1 (b),
we construct the interaction histories of representative users across10countries and diverse age demographics,
spanning over20distinct topic domains and extending the scope to include2,166preference details. Table 1
summarizes the resulting corpus, which contains upwards of800events across domains, with contexts totaling

process as illustrated in Figure 2. A timeline generation agent first transforms these events into detailed

relevant memory segments. Furthermore, we conduct probing evaluations at various temporal intervals along

2 Related Work
2.1 Evolution of Personalization Memory Benchmarks
2.1.1 Evaluating Long-Context Memory Capabilities of LLMs
The evaluation of long-context capabilities in LLMs [54, 66, 67] has historically relied on “Needle-in-a-Haystack”
style tests that measure a model’s ability to retrieve facts embedded within lengthy contexts [26, 37]. While
early benchmarks were limited to 10k-token interactions, recent efforts [32, 46, 48], such as LongMemEval [57]
extend evaluation to ultra-long multi-session dialogues ranging from 115k to over 1.5M tokens, incorporating
tasks that probe cross-session memory and free-form question answering. Nevertheless, these benchmarks
primarily evaluate whether models can access and reason over long interaction histories, rather than how user
preferences are incrementally inferred and integrated during ongoing interactions for personalization. Table 3
provides a comparison between existing memory and personalization evaluations across multiple dimensions.

2.1.2 T owards Personalization in Memory
At the core of personalized interaction and lifelong digital companions [58] lies the concept of user preferences [9,
41, 72], defined as the longitudinal collection of a user’s stable interests, stylistic inclinations, and task-specific
constraints [15]. For a personalized agent [17, 22, 64], these preferences constitute a latent state that must
be captured from historical interactions to guide subsequent response generation. This ensures that agent
behavior aligns with individual expectations without necessitating repetitive, explicit instructions. The
fundamental necessity of preference modeling is to alleviate the “interaction burden” – empowering agents to
proactively anticipate user needs from historical context, thereby enhancing efficiency and user satisfaction in
real-world applications.
Broadly, personalization benchmarks have evolved from (i) static preference conditioning to (ii) multi-session
preference retention, yet few explicitly evaluate whether models can maintain a coherent persona state
under evolving, information-dense interactions. Early frameworks, such as PrefEval [75] and PerLTQA [9],
characterized personalization as conditional response generation, focusing on an LLM’s capacity for long-
context understanding, user modeling and adherence to a constrained set of stated preferences. These
studies revealed that contemporary LLMs struggle to infer implicit preferences accurately and apply them
consistently across conversational turns, particularly when intervening dialogues introduce unrelated topics
as “contextual token noise” [46]. Despite these advancements, it remains designed for “Needle-in-a-Haystack”
tasks, in which isolated preferences are retrieved from vast volumes of unrelated context. To enhance the
recognition of personalized intent, UserBench [38] and PersonaLens [77] introduced interactive, gym-like
environments. These benchmarks advanced the field toward simulating real-world agent dynamics; however,
they treat user profiles as fixed inputs rather than evolving constructs. A pivotal shift toward memory
retention occurred with PersonaMem [19], which incorporated multi-session interaction histories. PersonaMem
centers on preference-driven dialogue construction; consequently, its dialogues resemble subjective opinion
sharing rather than objective problem solving. Subsequently, PersonaMem-v2 [20] further advances this
paradigm by focusing on implicitly expressed preferences and requiring LLMs to infer user traits from subtle
conversational nuances. It assumes that implicit behavioral cues can be consistently abstracted into stable

recall within constructed interaction traces, without explicitly probing the stability, cross-domain synthesis,
and temporal consistency of the underlying persona state. Recent efforts, such as the KnowMe-Bench [58], use
long-form narratives as a data substrate to evaluate evidence-grounded inference about motivation, identity
development, and psychological states. Yet KnowMe-Bench is better characterized as a reasoning benchmark
rather than as an assessment of personalized conversational user-assistant interaction or dialogue management.
To address these limitations, PERMA introduces a dynamic evaluation paradigm centered on active dialogue
management. We shift the evaluative focus from single-point preference recall to composite synthesis, requiring
memory systems to integrate interdependent traits across information-dense sessions to resolve complex queries.
By employing an event-driven methodology, our framework captures the evolutionary nature of user profiles;
specifically, the interplay between newly emerged and updated preferences, while moving beyond “black-box”
long-context reasoning evaluation through a decoupled assessment of retrieved memory quality and generative
reasoning. As a result, PERMA reframes personalization evaluation from preference identification to persona
state maintenance across temporally ordered events with structured noise and cross-domain dependencies.
Such requirements extend beyond traditional dialogue retrieval, motivating the development of dedicated
memory systems and memory-enabled agents for persistent user modeling.
2.2 F rom Static Retrieval to Persistent Memory
Personalization in LLMs has undergone a fundamental architectural shift driven by the growing mismatch
between transient context conditioning and the requirements of long-term user–assistant relationships [24, 64].
Early approaches implicitly equated personalization with prompt augmentation, assuming that user history
could be sufficiently represented within a fixed or expanded context window. However, this assumption fails
at scale: attention-based architectures exhibit context dilution and the “lost-in-the-middle” phenomenon,
rendering long-term user modeling inefficient [26].
Retrieval-Augmented Generation (RAG) [12, 29] reframed this problem by externalizing memory into non-
parametric storage. By enabling semantic access to repositories of user-related information, RAG alleviated
context window constraints and improved factual grounding. Yet this architectural move introduced a new
limitation: memory was reduced to static, document-like artifacts retrieved reactively based on semantic
similarity [23, 39]. RAG systems remain inherently stateless, primarily serving as indexing mechanisms for

user-assistant dialogue rather than modeling the temporal evolution and coherence of user personas [34].
Unlike passive retrieval in vanilla RAG, agentic frameworks utilize LLMs as reasoning engines to orchestrate
tool use [55, 69] and multi-step planning [73]. However, for an agent to exhibit consistent personality and
long-term adaptation, it requires a persistent memory system, which functions as the agent’s long-term storage.
Recent work [8, 53, 63, 74] has begun to formalize this transition by treating memory as a structured, lifecycle-
aware subsystem. Rather than storing immutable embeddings, memory architectures introduce mechanisms for
consolidation, reinforcement, decay, and reorganization [18,43]. This marks a shift from storage-centric memory
to process-oriented memory, in which the relevance of stored information is dynamically updated over time.
Memory systems that support fine-grained updates recognize that personalization must operate at multiple
levels, including episodic experience, user preferences, and behavioral patterns. MemOS [25] was among
the first to formalize memory as a core system component, introducing a lifecycle management mechanism
(MemCube) that enables dynamic memory scheduling, aging out obsolete facts while reinforcing relevant ones
over long horizons. Similarly, Mem0 [6] is a scalable memory-centric architecture that dynamically extracts,
consolidates, and retrieves salient conversational information from ongoing interactions, supporting persistent,
structured memory beyond raw document retrieval. Memobase focuses on extracting and maintaining
structured user profiles and tagged memory records from chat interactions, serving as a scalable backend for
personalized applications. Supermemory provides a unified memory API that builds structured relationships
between facts to support persistent recall and relational context beyond simple vector proximity. Compared
to existing benchmarks (Table 3), the differentiation of PERMA lies in the multi-dimensional decoupling of its
evaluation. While LLMs and memory systems have improved in memory capacity, they still lack a fine-grained
characterization of event-driven persona state evolution, which is essential for reflecting the mastery of user
preferences. Furthermore, by integrating context noise and temporal probing, PERMA enables us to verify
the coherence persona state within complex event streams, independent of mere interaction quality.

4 Methodology
In this section, we introducePERMA. Rather than treating personalization as static preference recall, our
framework models personalization as evolving preferences through an event-driven reconstruction of dialogue
histories (Section 4.1). To better reflect real-world user-assistant interactions, Section 4.2 introduces two
interaction variants by (1) injecting text variability based on common user prompt biases [50], (2) aligning
query linguistic styles with real-world data. We evaluate downstream queries that do not explicitly trigger
preference retrieval, thereby testing whether agents can proactively leverage stored information to integrate
and enforce composite, cross-domain preferences (Section 4.3).
4.1 Event-Driven Dialogue Reconstruction
We construct dialogue histories based on interaction summaries from PersonaLens [77], which are grounded in
authentic user profiles derived from the PRISM dataset [21]. These profiles span 20 distinct domains, ranging
from Movies to Flights. We extend these concise summaries into long-horizon, consistent dialogue histories
that capture the gradual emergence and iterative refinement of user preferences.

4.2 Alignment with Real-W orld Interactions
In event-driven persona state modeling, the inherent noise and disfluencies of real-world interactions present
significant hurdles. For example, user utterances can be vague, and preferences are often fragmented across
multiple messages. While prior research [19, 75] has introduced preference updates post multiple sessions, we
aim to incorporate a broader spectrum of text variability observed in human prompts for LLM [50], as well as
individual idiolects.
4.2.1 T ext V ariability Injection.
In natural interactions, user inputs frequently contain vague expressions, inconsistent preferences, or context
switch, as illustrated in Table 2. Such phenomena challenge personalized memory agents not only in retrieving
relevant information but also in integrating histories and composing accurate persona-state signals.
However, synthetic text is often standardized and lacks variability, even when using a high temperature for
generation [56]. To bridge this gap, we introduce a controlled noise injection process during dialogue generation.
Specifically, we perturb user turns with contextually grounded in-session noise that preserves conversational
plausibility. Building upon the original dialogue-generation prompt and extracted preferencesΦ, we augment
the generation process by providing a noise specificationZ that describes the intended perturbation type
(e.g., omitted references, context switch, or inconsistent preferences). We also generate examples conditioned
on Z, which are incorporated as one-shot in-context demonstrations [3] in noise specification to guide the
dialogue generation agent.

4.2.2 Linguistic Alignment.
Real-world user inputs exhibit individual idiolects. In contrast, synthetic conversations often follow standard-
ized templates, which simplifies retrieval and artificially inflates evaluation, especially when the generator
and the agent share the same underlying model. To prevent models from exploiting overt lexical cues, we
construct user prompts to mimic the authentic linguistic patterns observed in real-world interaction corpora.
Specifically, we randomly sample real-world conversations from WildChat [76] for each user prompt in the
Cleansetting, and instruct an LLM to align the linguistic style of the synthetic user prompt with the real
data, while preserving the underlying user intent. In addition, we interleave WildChat data as irrelevant
distractors within the global timeline, extending the total context up to 128k tokens. This design challenges
models to infer persona states from diverse, individualized linguistic patterns across long-context sessions,
thereby increasing the tasks’ complexity.
Together, text variability and linguistic alignment ensure that our evaluation extends beyond idealized
preference recall. Instead, PERMA probes the model’s capacity to maintain coherent persona-state tracking
even in the presence of pervasive ambiguity and authentic linguistic variability.
4.3 Evaluation Protocol
To systematically evaluate persona state tracking across temporal depths and contextual complexities, PERMA
adopts a multi-dimensional evaluation protocol. This protocol integrates temporally controlled task insertion
to evaluate cross-session evolution, positional probing within long contexts to assess retrieval robustness, and
comprehensive metrics that capture both factual correctness and persona consistency.
4.3.1 Evaluation Checkpoints (Type 1/2/3).
Checkpoints are strategically inserted into the global timeline to probe distinct stages of persona-state
development. Type 1 (Zero-Memory) tasks are placed before any domain-relevant events occur, serving
as a zero-memory baseline to disentangle the agent’s parametric bias from its persona-based responses.
Type 2 (In-Time) tasks are introduced immediately following the emergence of all relevant domains to assess
peak recall. Finally, Type 3 (Post-Intervention) tasks are placed at the end of the global timeline, after
multiple intervening sessions. At this stage, the persona state is fully developed but heavily occluded within a
substantially longer and noisier history.
4.3.2 Contextual Position Probing.
In addition to temporal stage control, we probe evaluation tasks at varying positions within contexts (e.g.,
10%–100% event segments of the histories). By measuring performance as a function of this relative distance,
we analyze how different personalized memory agents balance retrieval efficiency and contextual scanning.
This positional probing provides a fine-grained view of how persona state utilization degrades or stabilizes as
context length increases.
4.3.3 Metrics and Assessment Dimensions.
Evaluation is conducted along three primary dimensions: task performance, memory fidelity and efficiency.
Task PerformanceWe evaluate system performance in both one-shot and interactive settings. In the former,
we employ Multiple-Choice Question (MCQ) to measure selection accuracy (MCQ Acc.). The MCQ options
are generated by ablating three core aspects: (i) Task Completion, indicating the fulfillment of defined goals;
11

=== PAGE 12 ===
(ii) Preference Consistency, ensuring responses are grounded in long-term preferences without hallucinating
unsupported inferences; and (iii) Informational Confidence, identifying whether the model maintains a decisive
stance without uncertainty (see Figure 18 for details). By enumerating all binary combinations of three
aspects, we yield eight distinct evaluation categories.
To better approximate real-world usage, we introduce an interactive evaluation using an LLM-based user
simulator (see Figure 16 for the prompt). The simulator is granted access to the ground-truth dialogue history
and relevant preference annotations. It terminates the session by outputting “TERMINATE” only when the
task is completed while satisfying all user preferences. Otherwise, it provides supplementary feedback, and
the dialogue continues.
We report the success rate atTurn=1 and Turn≤2. Compared to the one-shot setting, the interactive evaluation
not only assesses open-text responses but also distinguishes suboptimal memory (resolvable with a single
feedback round) from low-quality memory (requiring extensive clarification). Interactions are capped at a
maximum of 10 turns. We report taskCompletion representing the percentage of tasks successfully terminated
within this interaction limit, serving as a measure of overall system reliability.
Memory FidelityWe calculate the BERT-f1 between the retrieved context and ground-truth dialogues,
complemented by aMemory Score (see Figure 19) derived via “LLM-as-a-judge”. This protocol evaluates task
coverage, accuracy, and preference consistency. Specifically, this scoring mechanism penalizes the omission of
critical persona facets while rewarding concise, task-relevant retrievals that enhance downstream utility.
EfficiencyWe calculate Context Token to measure the average number of memory tokens consumed per
query. To quantify memory retrieval efficiency within long-context environments, we also record theSearch
Duration. In the interactive setting,User Token tracks the total tokens generated by the user simulator,
capturing the communicative overhead and degree of preference clarification required to resolve a task.

MCQ options to verify their quality. Given the ground-truth dialogue history, human experts achieve an
impressive 97.75% accuracy on the tasks, demonstrating high alignment between the task objectives and the
provided dialogue data.
Beyond the MCQ tasks, human experts evaluate additional content generation aspects using the criteria
protocol detailed in Figure 20. Specifically, we assess whether the constructed events accurately cover the goals
and descriptions specified in the timeline entries (as described in Section 4.1.1), yielding a near-perfect score
of 1.99/2. Regarding the injection of text variability, experts find that 98% of the generations successfully
adhere to the designated noise types, confirming the efficacy of our text variability injection process.

5.2.4 Performance Dynamics in Multi-Domain Noise Scenarios
In the multi-domain noise environment, the performance of standalone LLMs diverges significantly from
memory systems-based agents, revealing critical insights into reasoning capacity and retrieval efficiency.
1. Performance of Standalone LLMs.As indicated in Table 7, standalone LLMs with enhanced reasoning
capability, such as Kimi-K2.5, demonstrate substantial resilience to text variability and the complexity of
multi-domain queries, maintaining a robustMCQ Acc. of0.930. It suggests that advanced reasoning is
a pivotal driver in stable preference formation, especially navigating environments with high contextual
entropy. In contrast, chat models such as Llama3.3-70B suffer a performance degradation, with accuracy
falling to0.656. highlighting a significant susceptibility to complex tasks with high contextual entropy.
2. Performance Changes in Interactive Scenarios.Figure 8 shows the performance fluctuations of memory
system-based agents compared to standalone LLMs in the presence of noise. Notably, memory systems
exhibit higher sensitivity, particularly during interactive tasks where response accuracy drops after noise is
introduced. This degradation is more pronounced than that observed in the single-domain setting shown
in Figure 4. These results suggest that while current memory systems decompose queries [31] and rerank
retrieved memory, they still struggle to integrate and properly order information across domains when
dealing with noisy environments.
Finally, taking a holistic view of Figure 9, we observe that, when comparing performance between the Type 3
and Type 2 positions, memory systems generally maintain stableTurn=1 performance and remain largely
robust to token-level noise introduced by irrelevant dialogue. Moreover, relative to the no-memory baseline
(Type 1), they achieve consistent and steady improvements. However, compared to the single-domain
tasks, the disparity among different memory systems becomes more pronounced in the multi-domain
evaluation, particularly at the Type 2 position, suggesting that memory systems differ in their sensitivity
to cross-domain complexity.

To evaluate the limits of standalone LLMs and memory systems, we extend our experiments to a long context

stress-tests models’ ability to maintain effective memory under extreme context lengths. Following the pipeline
described in Section 4.2.2, we align the user queries of theCleansetting with real-world conversational styles
and populate the context with authentic dialogue segments sampled from WildChat [76].
1. The Impact of Stylistic Interference and T oken-level Noise.In the single-domain task performance
shown in Figure 8, comparing the base metrics (Clean setting in Table 4) to the style-aligned results shows

exhibit remarkable stability. By transforming the global long-context reasoning problem into a persona-state
matching task, MemOS effectively bypasses the physical context window limitations of the underlying

4. Robustness under Positional Probing.Compared to prior work that evaluates preference at a fixed

stable accuracy, surpassing even the Qwen2.5-14B-1M. This stability suggests that its indexing mechanism
successfully handles semantic overlap and retrieval interference in dense context segments.

5.3.3 T opic-Specific Adaptation and Domain Expertise
Table 10 reveals clear domain-specific performance variations across different approaches. Large-scale models
such as Kimi-K2.5 achieve the strongest results in structured domains like Finance (0.914) and Messaging
(0.980), where task requirements are relatively stable. Within the memory systems, MemOS narrows the
gap between plug-in memory-based agents and vanilla models, particularly in the Shopping (0.889) and
Travel (0.856) domains, demonstrating improved utilization of historical preferences. In contrast, a consistent
performance drop is observed in the Media and Restaurant domains across all evaluated models. These
domains typically involve more dynamic and frequently updated user preferences, making them inherently
more challenging. This suggests that memory should not function solely as a storage of historical interactions
and preferences, but should be actively leveraged to guide future responses by transforming accumulated
preference signals into informative priors for inference.
6 Conclusion
In this work, we introduce a benchmark that shifts the evaluation of personalized memory agents from static
preference recall to persona consistency. By constructing temporally ordered interaction events, we propose
an event-driven framework, PERMA, for assessing LLMs and memory systems under text variability and
real-world linguistic alignment. Our experiments in single- and multi-domain tasks reveal that most memory-
based systems outperform RAG by linking related interactions into a persistent persona state. This advantage
becomes more pronounced in high-entropy settings, where memory systems demonstrate greater robustness and
achieve 300× higher token efficiency than vanilla long-context models. Notably, while standalone LLMs exhibit
severe performance degradation when context exceeds their window sizes, memory systems remain stable
by reducing long-range reasoning to structured persona state matching. Despite these gains, performance
degradation under multi-domain transitions and conflicting signals reveals a sensitivity to context complexity,
highlighting the necessity of PERMA. Overall, our findings suggest that, while memory enhances robustness,
achieving personalized agents requires moving beyond static retrieval toward task-aware memory management
capable of filtering noise and maintaining long-term coherence, enabling lifelong companionship.

Appendix
A Prompt
To establish a realistic foundation for evaluation, the framework utilizes data construction prompts that
simulate the evolution of user preferences. By leveraging TIMELINE_GENERATION in Figure 13, the
system generates interaction timelines, modeling how user interests emerge and deepen. These timelines are
then transformed into naturalistic dialogues via the DIALOGUE_GENERATION prompts in Figure 15,
which guide the LLMs to reveal preferences through feedback or corrections, thereby mirroring the ambiguity
of real-world interactions.
Building upon this data, the framework transitions to a dynamic interactive simulation driven by the User
simulator. As the interaction unfolds, the USER_FEEDBACK_PROMPT in Figure 16 provides the user’s
responses, enabling the agent to provide adaptive feedback. This mechanism allows the simulated user to
clarify intent or correct the assistant based on history, creating a test of the assistant’s ability to maintain
consistency and adapt to user guidance in real-time.
Finally, to quantify agent performance, the module implements a standardized “LLM-as-a-Judge” evaluation.
We score the assistant’s responses on quality and personalized memory (EVAL_MEMORY_SCORE in
Figure 19). Crucially, the system assesses memory precision, verifying the retrieval of details against ground
truth. OPTION_GENERATION_PROMPT in Figure 18 synthesizes challenging multiple-choice questions
with options that are plausible but intentionally misaligned with user preferences or facts, thereby testing the
agent’s discriminative ability in noisy environments.
B Case Study
In this section, we present a case study comparing the retrieved memory of different systems to provide a clearer
horizontal evaluation. As illustrated in Table 11–12, we can intuitively observe the retrieved memory results of
various systems for the same query: MemOS categorizes memory into three distinct dimensions—episodic facts,
explicit preferences, and implicit preferences—utilizing a parallel retrieval mechanism that effectively addresses
the three categories of challenges inherent in preference-driven scenarios; meanwhile, Mem0, Memobase,
and EverMemOS prioritize the concatenation of episodic memories, which makes them better suited as
personal assistants for querying historical records but leaves them relatively weak in preference extraction
and processing; conversely, Supermemory leans toward highly abstracted preference extraction but fails to
reconstruct the specific details of relevant events along the timeline.
